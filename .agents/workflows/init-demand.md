Pour commencer comprends le projet par exploration.

REGLES :
- Vérifie tes hypothèses. 
- Toute hypothèse non vérifiée totalement, également dans ces causes et implications, sur le code est invalidée.
- Le code de produits tiers utilisés dans le projet, mais non sous la repsonsabilité du projet , dont open-webui, qdrant ..., se situe dans /.tmp_audit, pour lecture.
- La création de script pourexécuter des tâches se fait dans .tmp_audit

METHODOLOGIE :
- Nous dicutons sans coder pour commencer afin d'affiner et comprendre ce qu'il faut faire
- Produisons des plan intéractif (/plan) pour s'assurer de suivre la bonne solution retenue


PROBLEMATIQUE ET CONTEXTE
Tu dois resituer la problématique dans le contexte d'ECHO en renforçant au besoin ton exploration du projet

PREREQUETE INITALE: 
Analyse les opportunités de correction, et la faisabilité de résolution, des problématiques soulevées.
Ne code pas, analyse.
