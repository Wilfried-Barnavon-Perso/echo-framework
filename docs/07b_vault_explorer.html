7b. Vault & Data Explorer

Ce module constitue la porte d'entrée vers les "données froides" du Vault utilisateur. Il permet l'exploration, l'audit et l'analyse sémantique de fichiers massifs sans saturer la fenêtre de contexte du modèle PRO.

Exploration Brute (read_raw_file_content)

Contrairement aux lecteurs standards, ECHO implémente une lecture paginée "Tell-Safe" pour éviter les bugs d'itération sur les fichiers volumineux.

Injection Multimédia Native (read_multimedia_file)

Cette fonction majeure permet au modèle d'accéder directement au contenu binaire d'un fichier (Image, Vidéo, Audio, PDF) sans passer par une analyse intermédiaire. Le fichier est injecté directement dans le cortex multimodal de Gemini.

Spécifications Techniques (ECHO v5.99+)

  • Capacité : Jusqu'à 100 Mo (configurable via la valve MAX_MULTIMODAL_SIZE_KB).
  • Protocole : Encodage Base64 injecté via le paramètre echo_tool_multiparts.
  • Types Supportés : Tous les types MIME définis dans MIME_MAPPING_BIN (MP4, MP3, PNG, JPG, PDF, etc.).
  • Rétroaction UI : Utilise EchoEvents pour afficher le statut du chargement binaire en temps réel à l'utilisateur.

Limitation de Sécurité Gemini

Toute sortie brute est bridée à 16 Ko pour garantir la conformité avec les APIs Gemini et prévenir les plantages de flux. Pour les fichiers plus gros, utilisez les byte_offset.

Mode Spécification Technique
text Lecture ligne par ligne avec préfixe d'index (120 | contenu). Idéal pour le code source.
base64 Lecture binaire brute. Utilisé pour transférer des morceaux de fichiers vers d'autres outils (ex: conversion).
hex Affichage hexadécimal indexé. Indispensable pour l'audit de fichiers binaires ou corrompus.

Sondage Sémantique (semantic_probe)

L'une des fonctions les plus puissantes d'ECHO. Elle permet de déléguer l'analyse d'un document entier à une instance Gemini Flash dédiée (moins coûteuse en tokens pour le modèle principal).

  • Délégation : Le modèle PRO demande une analyse (ex: "Quels sont les points clés de ce contrat ?").
  • Audit : Le modèle FLASH lit le document intégral et renvoie une synthèse structurée.
  • Multipart : Les pensées internes du modèle FLASH sont encapsulées dans la section thought du multipart.
  • Thinking Levels : Supporte les niveaux MINIMAL, LOW, MEDIUM et HIGH pour ajuster la précision de l'analyse.

Visualisation Premium Image Viewer (show_image_to_user)

ECHO v5.104.0 introduit le Premium Image Viewer, une interface HUD interactive unifiée capable d'afficher des sources locales (Vault) et distantes (URL).

Fonctionnalités Avancées du Viewer

  • Détection Agnostique : L'outil show_image_to_user détecte automatiquement si la cible est une URL ou un ID de fichier.
  • Moteur Zoom & Pan Universel : Navigation haute fidélité via la matrice de transformation CSS (transform: scale() translate3d()). Ctrl + Molette gère le zoom, Clic + Glisse gère le Pan (déplacement matriciel au pixel près).
  • Outil d'Extraction (Crop) : Tracé d'une zone de sélection mathématiquement liée au ratio de zoom, permettant d'extraire directement l'image ciblée (Canvas 2D) vers le presse-papier avec un Fallback CORS natif et copie visuelle.
  • Pure Context Return (v5.105.1+) : Contrairement aux anciens modules, l'outil renvoie désormais une string pure au lieu d'un dictionnaire, évitant au LLM d'ingérer un wrapping JSON inutile et concentrant son attention contextuelle sur les faits bruts.
  • Stealth Engine : Pour les images distantes, ECHO utilise un moteur de mimétisme humain (Chrome 123 sur Windows 11) pour contourner les protections anti-hotlinking et les redirections (302/403).
  • Souveraineté : Les images du Vault restent injectées en Base64, garantissant qu'aucune donnée privée ne quitte l'enclave utilisateur vers des services de rendu tiers.

Moteur de Téléchargement Stealth (download_from_url)

Le module de téléchargement a été intégralement refondu pour simuler un comportement humain parfait :

Fonctionnalité Spécification Technique
Follow Redirects Suivi systématique des redirections HTTP (301/302). Indispensable pour des services comme Picsum ou Unsplash.
Stealth Headers Injection d'en-têtes sec-ch-ua, Referer dynamique et User-Agent premium pour lever les blocages 403.
Final URL Capture Extraction de l'URL réelle de destination après redirection pour une indexation précise dans le Vault.

Intégrité & Métadonnées

Fonction Rôle Technique
get_file_metadata Extraction des attributs système (Taille, MimeType, Date de modification).
calculate_file_hashes Calcul du hash SHA-256. Indispensable pour vérifier l'intégrité après un téléchargement ou une manipulation sandbox.

Gestion des Identifiants (IDs)

Tout fichier dans ECHO est référencé par un file_id souverain généré par echo_utils.generate_echo_file_id. Ce format inclut l'ID utilisateur, l'ID du chat et un timestamp milliseconde, garantissant l'unicité absolue dans le Vault.
