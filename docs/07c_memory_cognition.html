7c. Cognition Profonde & Mémoire Organique

L'intelligence d'ECHO v5 repose sur une dualité fondamentale : le Cortex Réactif (Le Pipe) et le Registre Cognitif Persistant (La Mémoire). Cette architecture garantit une puissance de calcul maximale tout en préservant une cohérence historique absolue.

1. Architecture de la Cascade Cognitive (Le Cortex)

Le Pipe Engine (pipe_engine.py) n'est pas un simple tunnel de données. C'est un moteur de routage dynamique bidirectionnel qui gère la puissance de calcul en temps réel.

A. Cascade Native & Outil Virtuel d'Ajustement

Lors d'une requête en mode AUTO, ECHO initialise systématiquement la session sur MODEL_LITE (le point d'entrée par défaut). Cependant, le Cortex injecte dynamiquement un outil virtuel invisible pour l'utilisateur : changement_niveau_cognitif.

Mécanique de l'Escalade & Redescente

Cet outil permet au modèle actuel de modifier sa propre puissance de calcul selon deux lois fondamentales :

  1. Loi de Nature de Tâche :
    • MODEL_LITE (Réflexe) : Salutations, extractions simples, culture générale basique.
    • MODEL_FLASH (Exécution) : Recherche web, scripts isolés, synthèse unitaire, outils simples.
    • MODEL_PRO (Expertise) : Architecture, orchestration, refactoring complexe, philosophie profonde.
  2. Loi de Corrélation Contextuelle (La Vallée de la Mort) : Plus le contexte (tokens) s'alourdit, plus le niveau cognitif doit augmenter pour maintenir la cohérence, indépendamment de la simplicité de la tâche. Si le contexte dépasse 50% de la fenêtre, le passage en MODEL_PRO est impératif.

B. Délégation Explicite (Cognitive Core)

L'outil delegate_reasoning permet à l'orchestrateur de déléguer consciemment une portion de la tâche à un sous-système. Contrairement à la cascade native (qui change de modèle pour la réponse en cours), ici le résultat est réinjecté comme une donnée isolée.

Modèle Cible Niveau de Pensée (Valve) Usage Recommandé (Délégation)
MODEL_PRO PRO_THINKING (HIGH) Debug de fichiers multiples, Planification multicouche.
MODEL_FLASH FLASH_THINKING (HIGH) Formatage JSON complexe, Traduction sémantique riche.
MODEL_LITE LOW Distillation de texte brut, Résumé de documents volumineux.

2. Mémoire Organique V2 : La Suture Sémantique

La mémorisation dans ECHO n'est pas un simple stockage de logs. C'est un pipeline de distillation vectorielle géré par le filtre conversation_memory_filter.py.

A. Le Cycle de Mémorisation (Non-bloquant)

Le déclenchement est piloté par deux facteurs : la probabilité (TRIGGER_PROBABILITY=0.1) et le seuil de sécurité (FORCE_TRIGGER_THRESHOLD=20 messages). Une fois déclenché, le pipeline s'exécute en tâche de fond :

Pipeline Technique de Mémorisation

1. Distillation (Gemini 2.5 Flash) -> Génère un JSON (Summary, Importance 1-5, Slug, Tags)
2. Vectorisation (Gemini Embedding 2) -> 3072 Dimensions, Distance: Cosine
3. Recherche (Qdrant) -> Similarité Seuil 0.85
4. Action :
   - Similitude < 0.85 : Création d'un nouveau point vectoriel.
   - 0.85 < Similitude < 0.95 : Fusion LLM (Ancien + Nouveau) pour mise à jour sémantique.
   - Similitude > 0.95 : Simple "Touch" (Mise à jour du timestamp de rétention).

B. Gouvernance des Données & TTL (Time To Live)

chaque souvenir possède une date d'expiration calculée dynamiquement selon son importance :

  • Niveau 1 (Éphémère) : 30 jours (Trivial / Éphémère).
  • Niveau 2 (Utilitaire) : 60 jours (Contexte de session étendue).
  • Niveau 3 (Structurel) : 180 jours (Préférences techniques, noms de projets).
  • Niveau 4 (Fondateur) : 365 jours (Logique métier stable, décisions d'architecture).
  • Niveau 5 (Axiome) : 540 jours (Règles de sécurité, Principes ECHO fondamentaux).

3. Interaction Cortex / Registre

L'IA utilise l'outil memory_organic_tool.py pour interroger son registre. Cela permet de décider *quand* elle a besoin de contexte historique, évitant ainsi le "bruit" dans la fenêtre de contexte actuelle.

Spécifications Qdrant

  • Collection : echo_memory
  • Partitionnement : Isolation stricte par user_id via payload filter.
  • Indexation : HNSW pour une recherche ultra-rapide.
