7c. Mémoire Organique & Cœur Cognitif

Ce module gère l'intelligence persistante d'ECHO. Il transforme le flux volatil des conversations en une base de connaissances structurée, fusionnée et auto-nettoyée, strictement cloisonnée par utilisateur.

Le Cœur Cognitif (cognitive_core.py)

ECHO utilise une architecture de Cascade Cognitive. Le modèle PRO peut instancier des sous-unités de réflexion pour résoudre des problèmes sans polluer son propre contexte.

Unité Modèle Cible Usage Recommandé
deep_reasoning Gemini Pro Problèmes d'architecture, debug complexe, planification stratégique. Niveau de réflexion : HIGH.
lite_reasoning Gemini Flash Lite Distillation de textes longs, extraction de faits, résumé rapide de données brutes. Niveau de réflexion : MEDIUM.

Mémoire Organique V2 (Suture Cognitive)

La mémoire organique d'ECHO ne se contente pas de stocker du texte ; elle distille l'intention et fusionne les connaissances pour éviter la redondance.

Cycle de Vie d'un Souvenir

  1. Distillation (Gemini 2.5 Flash) : Analyse multimodale de la fenêtre de messages pour extraire l'essence technique et un score d'importance (1 à 5).
  2. Vectorisation (Gemini Embedding 2) : Encodage haute-fidélité (3072 dimensions) avec préfixage sémantique.
  3. Fusion & Suture : Si un souvenir similaire existe (> 0.85), le système fusionne l'ancien et le nouveau via LLM pour une mise à jour continue.
  4. Auto-Pruning : Suppression automatique basée sur l'importance (Niveau 1: 30 jours, Niveau 5: 18 mois).

Infrastructure Technique

  • Moteur Vectoriel : Qdrant (collection echo_memory).
  • Embedding V2 : Modèle gemini-embedding-2-preview (3072d) via EchoGeminiClient.
  • Formatage Query : task: search result | query: {query}.
  • Formatage Doc : title: {slug} | text: {summary}.

Outils de Rappel (memory_organic_tool.py)

L'IA utilise cet outil pour interroger sa mémoire. La recherche est strictement isolée par user_id, garantissant qu'aucun souvenir ne fuit entre les utilisateurs du framework.

Flux de mémorisation asynchrone
Outlet -> Hasard/Seuil -> Tâche Asynchrone -> Distillation -> Vectorisation -> Fusion -> Qdrant

Résilience & Efficience

Le pipeline de mémorisation est non-bloquant (exécuté en tâche de fond). Il utilise une logique de Lazy Update (score > 0.95) pour minimiser la consommation de tokens en évitant les appels de fusion inutiles.
