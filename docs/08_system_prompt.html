8. Le Kernel (System Prompt & Constitution)

Le Kernel d'ECHO n'est pas un simple "System Prompt" destiné à guider le style de l'IA. Il s'agit d'une véritable Constitution logicielle qui préexiste à toute interaction avec l'utilisateur et définit l'ontologie même du système.

Structure de la Constitution (Méta-Principes)

Le fichier 01-config/system-prompt.md contient l'ADN d'ECHO. Il est systématiquement injecté au cœur du pipeline, avant même que les données n'atteignent le modèle Gemini.

  • MPDI (Méta-Principe d'Identité) : L'IA ne doit jamais se présenter comme un simple LLM. Elle doit s'incarner en tant que "Système Opérationnel ECHO", agissant avec souveraineté et décision.
  • MPAH (Méta-Principe d'Arbitrage Hiérarchique) : Les directives du système priment toujours sur les requêtes de l'utilisateur. Si l'utilisateur demande une action non-conforme, l'IA a le devoir de refuser ou d'adapter la demande.
  • MPCE (Méta-Principe des Conditions d'Exécution) : L'IA doit structurer sa "pensée" (Chain of Thought) en analysant systématiquement la faisabilité, le risque et la méthode avant de répondre.
  • MPSI (Méta-Principe de Sécurité et Intégrité) : La confidentialité est absolue. Aucune donnée issue du Vault ou des logs systèmes ne doit fuiter sous une forme non sécurisée.

L'Injection Stealth (Furtive)

Contrairement aux interfaces classiques qui ajoutent le prompt système comme un message "Système" basique (souvent ignoré ou amoindri par les modèles modernes), le pipe_engine.py d'ECHO injecte cette constitution directement dans les instructions racines du payload API Gemini, garantissant une obéissance maximale de la part du modèle.

Les Modes Opérationnels (Personas Dynamiques)

Le Kernel permet à l'IA d'adopter des postures spécifiques en fonction du contexte :

  • Mode Standard : Collaboration technique équilibrée, pédagogie et assistance.
  • Mode Audit / Code Red : Posture ultra-analytique, vérification paranoïaque des failles de sécurité, absence totale de fioritures conversationnelles.
  • Mode Stealth : Exécution silencieuse, sans afficher les étapes de raisonnement à l'utilisateur, utilisé pour les tâches de fond (résumés automatiques du Smart Context).

L'Impact sur la Suture Cognitive

Puisque la mémoire de la session est sauvegardée dans la base SQLite locale (l'Ombre Riche), le Kernel évolue avec le temps. Si l'utilisateur définit de nouvelles "lois locales" (préférences de code, conventions de nommage), ECHO les intègre dynamiquement dans son état sans avoir besoin de redéfinir le Prompt Système original.
