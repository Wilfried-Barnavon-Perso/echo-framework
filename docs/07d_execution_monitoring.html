6d. Exécution Sandbox & Pilotage du Contexte

Pour exécuter des calculs complexes sans risquer la sécurité du système hôte, l'Arsenal dispose d'un environnement d'exécution isolé (Sandbox) et de sondes de surveillance.

Fiche d'Identité Technique

🐍 Exécution Sandbox & Pilotage

Nature : Environnement d'exécution de code isolé (Sandbox Docker) et Outil de diagnostic contextuel.

Source : 12-owui-tools/python_code_executor.py (Interface), 21-docker-python-worker/worker_api.py (Exécution), 12-owui-tools/context_gauge.py (Sonde).

Rôle : Permettre à l'IA d'exécute du code Python généré dynamiquement en toute sécurité et de surveiller l'état de saturation de sa propre mémoire de travail (Contexte).

Exécutant : Ordres émis par le Pipe (Python), code brut exécuté par le conteneur python-worker (isolé du réseau public).

Interconnexions :

  • Input : Scripts Python bruts générés par le modèle.
  • Sandbox : Le Worker exécute le script avec un timeout strict (30s) et intercepte stdout et stderr.
  • Output : Résultats textes bruts renvoyés au Pipe.

Ce module regroupe les outils permettant à ECHO d'exécuter du code de manière sécurisée et de surveiller sa propre santé cognitive.

Exécution Python Sandbox (python_code_executor.py)

ECHO dispose d'un environnement d'exécution Python isolé (conteneur python-worker). Cet outil est indispensable pour l'analyse de données et les calculs mathématiques complexes.

Architecture du Worker

  • Isolation : Le code s'exécute dans un environnement éphémère sans accès au Vault direct (sécurité par design).
  • Bibliothèques incluses : pandas, numpy, scipy, scikit-learn, networkx, requests.
  • Capacité Graphique : Désactivée (Environnement Headless). Toute tentative de génération visuelle échouera silencieusement.

Pilotage du Contexte (context_gauge.py)

L'outil d'auto-diagnostic contextuel. Il permet au modèle de connaître sa charge cognitive exacte (en tokens et en pourcentage) par rapport à sa limite théorique (Context Window).

  • Source de Vérité : Lit directement la table context_stats de la session SQLite utilisateur.
  • États de Charge :
    • ✅ SAFE (< 25%) : Navigation fluide.
    • âš ï¸ WARNING (> 25%) : Surveillance recommandée.
    • 🚨 CRITICAL (> 50%) : Risque de perte de mémoire à court terme.
  • Escalade Cognitive : Permet au modèle de décider s'il doit utiliser semantic_probe ou lite_reasoning pour compresser l'information avant la saturation.
