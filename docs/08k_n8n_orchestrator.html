ECHO N8N Orchestrator (Headless)

L'outil n8n_orchestrator_tool.py est le pont entre l'agent ECHO et le sous-système N8N Worker (Tier 2). N8N s'exécute de manière "Headless" sur SQLite (volume echo-n8n-data).

Règles d'Architecture strictes

  • Sandbox Éphémère : Tout workflow testé dynamiquement via CLI doit OBLIGATOIREMENT démarrer par le nœud Execute Workflow Trigger. Le mocking de payload asynchrone est impératif pour simuler les Webhooks/Emails.
  • Déploiements Permanents : Réservés aux webhooks de production et crons.
  • Child Chats : Les workflows N8N en mode Démon agissent comme des clients MCP, requêtant les services d'ECHO et ouvrant asynchronement de nouveaux "Child Chats".
