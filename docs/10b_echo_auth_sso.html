10b. ECHO Auth SSO & MFA

Le module ECHO Auth (hébergé dans docker-echo-auth) est le fournisseur d'identité (IdP) natif et autonome du framework. Il a pour vocation de remplacer complètement l'authentification interne d'Open WebUI par une solution externe centralisée offrant un niveau de sécurité entreprise.

Architecture et Forward Auth

ECHO Auth ne se contente pas de vérifier un mot de passe. Il est profondément intégré avec la sécurité périmétrique :

  • Point de passage unique : Lorsqu'il est activé, ECHO Auth devient le seul portail d'entrée. Il est couplé au WAF via l'endpoint /api/verify, protégeant l'ensemble de la pile de requêtes non autorisées (mécanisme de Forward Auth).
  • Authentification forte (MFA/TOTP) : L'authentification repose systématiquement sur un couple d'identifiants (email/mot de passe) suivi obligatoirement de la validation d'un code OTP temporel.
  • Gestion centralisée des sessions : Les jetons de session (JWT) émis par ECHO Auth peuvent être révoqués dynamiquement et unitairement depuis le Dashboard Actif de l'Admin Manager, offrant une capacité d'intervention immédiate en cas de compromission d'un accès.
