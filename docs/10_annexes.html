10. Annexes Techniques : Référence Deep-Dive

Cette section regroupe les spécifications brutes, la topologie réseau et les configurations de bas niveau indispensables à la maintenance du framework ECHO.

0. Topologie Réseau & Ports

ECHO orchestre un cluster de conteneurs sur un réseau Docker privé (echo-network). La passerelle BunkerWeb agit comme l'unique point d'entrée sécurisé.

Service Port Interne Port Hôte (Exposé) Rôle
Open WebUI 8080 3000 Interface utilisateur et moteur de Pipe.
Admin Manager 3001 3001 Dashboard de régulation et monitoring.
Qdrant 6333 6333 Base vectorielle (Mémoire Organique).
Python Worker 5000 - Sandbox Python (Arsenal).
Browser Agent 5002 - Moteur Playwright (Arsenal).

1. Persistance & Volumes Critiques

ECHO garantit la pérennité des données via des volumes Docker nommés. Le volume echo-webui-data est le pivot central de la "Vérité Sémantique".

  • echo-webui-data (Monté sur /app/backend/data) : Contient webui.db, le registre identity.db et toutes les bases SQLite de sessions (Ombres).
  • echo-qdrant-data : Stockage immuable des index vectoriels de Qdrant.
  • echo-backups : Destination des archives tar.gz générées par l'Admin Manager.
  • echo-worker-data / echo-browser-data : Espaces d'échange pour les artefacts d'outils.

2. Spécifications du Data Layer (SQLite / WAL)

ECHO utilise une architecture de stockage distribuée, isolée par identifiant utilisateur (UUID/ID) et par session (ChatID).

Global Registry : identity.db

Base centrale de l'utilisateur assurant la persistance de l'identité et de la sécurité.

3. Référence API des Classes Fondamentales

EchoGeminiClient

Protocole HTTP/2 Strict & Failover Hybride : Utilisation de httpx avec multiplexage. Réduit la latence des flux SSE et permet la capture asynchrone des signatures de pensée. Gère un "Mesh" d'authentification symétrique (AI Studio / OAuth2 Code Assist).

  • Bascule (Surcharge) : Rotation automatique après 2 échecs (429/500/503) avec Jitter (0.7x-1.3x).
  • Bascule (Autorisation) : Bascule **immédiate** vers l'identifiant suivant du mesh en cas d'erreur 403 (Forbidden) ou 404 (Not Found).
  • Monitor Streaming : Emission systématique de events.status lors des réessais pour garantir la transparence UX.

ECHO Cognitive Core

Interface de sous-traitance cognitive asynchrone pour l'exécution de tâches isolées (Stateless).

delegate_reasoning(context, prompt, target_model, ...)

Exécute une réflexion isolée sur un modèle cible avec injection sémantique obligatoire.

  • context (str) : Obligatoire. Faits et mémoire de référence (Markdown).
  • prompt (str) : Tâche ou instruction spécifique à accomplir.
  • target_model (enum) : Choix du moteur (MODEL_LITE, FLASH, PRO).
  • system_instruction (str) : Instruction système optionnelle pour forcer un comportement.

EchoStateManager

Merkle-Tree Core : Algorithme de double hachage pour la Suture.

  • Invariant Hash = SHA-256(role + content_sorted + tool_io)
  • Cumulative Hash = SHA-256(invariant + parent_hash)
