Serveur MCP Broker

Le Model Context Protocol (MCP) Broker agit désormais comme un Proxy HTTP complet (m5_proxy_mcp.py) exposant via ASGI des outils externes à l'architecture ECHO.

Il implémente une architecture robuste intégrant :

  • Forwarding d'erreurs : Remontée transparente des erreurs d'exécution des outils externes directement vers le LLM pour correction autonome.
  • Middleware d'Authentification ASGI : Interception silencieuse de l'en-tête x-openwebui-user-id au niveau ASGI pour sécuriser toutes les requêtes entrantes.

Modules Actifs

  • Corporate (Sirene/Bodacc) : Outils de recherche de données d'entreprise.
  • Academic : Interfaçage avec des bases de connaissances scientifiques.
  • Omnisearch Jobs : Moteur de recherche d'offres d'emploi.

L'Identity Vault fusionne dynamiquement les schémas de ce Broker avec l'API locale N8N pour la distribution sécurisée des secrets.
