8l. Serveur MCP Broker

Serveur MCP Broker

Le Model Context Protocol (MCP) Broker expose via ASGI des outils externes à l'architecture ECHO. Il est géré via FastMCP sous Uvicorn.

Modules Actifs

  • Corporate (Sirene/Bodacc) : Outils de recherche de données d'entreprise.
  • Academic : Interfaçage avec des bases de connaissances scientifiques.
  • Omnisearch Jobs : Moteur de recherche d'offres d'emploi.

L'Identity Vault fusionne dynamiquement les schémas de ce Broker avec l'API locale N8N pour la distribution sécurisée des secrets.
