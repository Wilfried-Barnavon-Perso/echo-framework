💡 Pourquoi l'Ombre Riche et la Suture ?

Les interfaces standards comme Open WebUI (OWUI) souffrent d'une amnésie structurelle : elles perdent le détail des appels d'outils et des fichiers entre chaque tour. Pour corriger cela, ECHO désactive le RAG natif d'OWUI au profit de son propre moteur. ECHO génère une Ombre Riche (un miroir parfait de la session) et pratique une Suture Cognitive : il recoud l'historique complet avant chaque envoi à l'IA, garantissant que Gemini "voit" tout ce qui a été fait, même les pensées cachées et les retours d'outils.

Glossaire de Précision Technique

📡 AEC (Artéfacts Environnementaux)

Définition : Composante dynamique certifiée du Framework injectée en XML.

Précision : Regroupe <etat_echo> (proprioception infrastructurelle) et <smart_context> (distillation sémantique). Ces balises constituent la frontière cognitive entre le système et l'utilisateur.

🎨 Rendu Visuel (Arsenal Visuel)

Définition : Système d'Exploitation Visuel multimodal.

Précision : Permet au modèle de déployer des interfaces interactives (Rich UI) via une délégation cognitive. Supporte nativement Markmap (Mental), Mermaid (Structure) et ECharts (Finance/Data).

👤 L'Ombre (Rich Shadow)

Définition : Enregistrement Bit-Perfect d'un tour de parole dans SQLite.

Précision : Contrairement au texte visible dans le chat, l'Ombre contient la structure JSON brute (Multiparts) envoyée à l'API. Elle conserve les binaires Base64, les appels d'outils (`tool_calls`) et les pensées internes (`thoughts`) que le Middleware Open WebUI ignore ou tronque.

⚓ La Suture (Cognitive Suture)

Définition : Algorithme de restauration de la continuité sémantique.

Précision : Processus par lequel le Pipe intercepte la liste de messages incomplète d'Open WebUI et la "recoud" en injectant les **Ombres** correspondantes. Cela garantit que chaque nouvelle inférence Gemini s'appuie sur une vérité historique absolue et non sur un résumé de dégradé.

📝 Le Draft (Brouillon Sémantique)

Définition : État mémoire volatile créé par le Filtre en phase Inlet.

Précision : Conteneur JSON (injecté dans `metadata`) regroupant les métadonnées de fichiers, les résultats du Smart Context et les signatures de sécurité. Le Draft est la "matière première" que le Pipe fusionnera lors de la Suture.

⚓ L'Ancre (Cognitive Anchor)

Définition : Identifiant de session persistant (`thoughtSignature`).

Précision : Jeton cryptographique fourni par l'API Google permettant de référencer un état de réflexion complexe mis en cache côté serveur. L'usage des Ancres réduit le poids du contexte de 30 à 70% lors de la Suture.

🧱 Le Moulage (Semantic Molding)

Définition : Compression sémantique de fichiers massifs via Gemini Flash.

Précision : Transformation d'un document brut (ex: PDF > 1 Mo) en un résumé technique structuré et indexé. Ce moulage permet au modèle principal (PRO) de manipuler des données massives sans saturer sa mémoire de travail immédiate.

Lexique Opérationnel & Définitions

Pour comprendre l'architecture ECHO, chaque concept doit être défini par sa nature technique et sa place dans le flux de données.

🌒 Le Filtre (Inlet)

Nature : Middleware d'interception de type Filter (Open WebUI).

Source : 11-owui-filters/new_context_filter.py

Rôle : Intercepte la requête. Gère le "Smart Context" (préanalyse des fichiers) pour décharger le modèle principal. Prépare l'état initial dans echo_shadows.db.

Exécutant : Instance Python d'Open WebUI.

Connexions : Reçoit de l'Utilisateur ; Alimente le Pipe via les métadonnées.

⚙️ Le Pipe (Outlet)

Nature : Moteur d'orchestration de type Pipe (Open WebUI).

Source : 10-owui-pipes/pipe_engine.py

Rôle : Se présente comme un modèle de GenAI auprès d'OWUI. Pratique la Suture Cognitive, gère les appels Gemini et la boucle d'outils de l'Arsenal.

Exécutant : Instance Python d'Open WebUI.

Connexions : Point central entre OWUI, Gemini et l'Arsenal.

🗄️ Ombre Riche (Rich Shadow)

Nature : Base de données relationnelle persistante (SQLite).

Source : /app/backend/data/user_dbs/echo_shadows.db

Rôle : Registre immuable de la vérité cognitive (pensées CoT, logs outils, signatures). Permet la Suture bit-perfect.

Exécutant : Moteur SQLite3 invoqué via les librairies 14-owui-libs/echo_utils.py.

Connexions : Consultée et mise à jour par le Filtre et le Pipe.

🛠️ L'Arsenal

Nature : Micro-services conteneurisés (Sandboxed API).

Source : Dossiers 20-docker-*.

Rôle : Exécution concrète des outils (Python, Navigation Web, Recherche).

Exécutant : Conteneurs Docker isolés (Python Worker, Browser Agent).

Connexions : Piloté par le Pipe via des appels HTTP REST internes.

Pipeline de Suture Cognitive

Le framework ECHO repose sur un constat critique : l'historique standard est incomplet. Pour garantir que Gemini conserve une mémoire parfaite, ECHO implémente une Ombre Riche : un miroir haute-fidélité capable de "réparer" et de "suturer" l'historique avant chaque envoi à l'API Gemini.

Infrastructure de Données & Moteur de Hachage

Le cœur technique de la persistance réside dans la classe EchoStateManager (14-owui-libs/echo_utils.py). Elle garantit qu'aucune information cognitive ne soit dégradée par l'interface middleware.

Algorithmes de Hachage (Merkle Core)

1. Invariant Hash : SHA-256(role + content_sorted + tool_io). Identité pure du tour.

2. Cumulative Hash : SHA-256(invariant + parent_hash). ADN de la conversation.

✅ Le point sur l'exactitude

Le Verrou de Version compare le triplet (message_id, updated_at, parent_hash). Si un Ghost Message (message modifié manuellement dans OWUI) est détecté, le Kernel bascule en Cold Recovery pour préserver la vérité sémantique.

Cold Recovery : Si l'Ombre SQLite est perdue, corrompue ou désynchronisée, ECHO bascule en mode de récupération à froid. Il utilise alors le texte brut fourni par le middleware Open WebUI, perdant temporairement les pièces jointes binaires passées et les appels d'outils, mais évitant le crash complet de la conversation.
