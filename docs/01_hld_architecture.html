1. High-Level Design (HLD)

💡 Le Concept en 1 minute

ECHO possède une double conscience. D'un côté, le chat que vous voyez. De l'autre, l'Ombre Riche : une base SQLite qui enregistre tout (pensées CoT, logs d'outils, fichiers). Le système "recoud" (suture) l'historique avant chaque message pour que l'IA ne perde jamais le fil de sa réflexion.

Pipeline de Suture Cognitive

Le framework ECHO repose sur un constat critique audité sur l'architecture standard : l'historique des messages est volatil. Pour garantir que Gemini conserve une mémoire parfaite, ECHO implémente une Ombre Riche : un miroir haute-fidélité de la session capable de "réparer" l'historique avant chaque envoi à l'API Gemini.

Infrastructure de Données & Moteur de Hachage

Le cœur technique de la persistance réside dans la classe EchoStateManager (14-owui-libs/echo_utils.py). Elle garantit qu'aucune information cognitive ne soit dégradée par l'interface middleware.

Algorithmes de Hachage (Merkle Core)

1. Invariant Hash : SHA-256(role + content_sorted + tool_io). Identité pure du tour.

2. Cumulative Hash : SHA-256(invariant + parent_hash). ADN de la conversation.

✅ Audit de Vérité (v180.2)

Le Verrou de Version compare le triplet (message_id, updated_at, parent_hash). Si un Ghost Message (message modifié manuellement dans OWUI) est détecté, le Kernel bascule en Cold Recovery pour préserver la vérité sémantique.
