9. Admin Manager (Surveillance & Lifecycle)

💡 Le Concept en 1 minute

L'Admin Manager est le Gardien de la Citadelle. C'est un service à part qui surveille si tout fonctionne bien : il vérifie que les bases de données sont en bonne santé, il nettoie les vieux fichiers inutiles pour faire de la place, et il vous permet de gérer les accès de sécurité globale. C'est l'outil indispensable pour l'administrateur qui veut garder son système ECHO performant sur la durée.

Le module server.py (situé dans 20-docker-admin-manager/) agit comme le poste de pilotage infra d'ECHO. Il assure l'interopérabilité entre les couches logicielles et l'orchestration Docker.

Fonctionnalités Techniques

  • Secret Maître : L'API /api/admin/password lit physiquement le fichier monté dans l'enclave /app/secrets/.owui-admin-secret.
  • Purge des clés (Auth Reset) : Parcourt tous les fichiers identity.db pour invalider les connexions SSO globales.
  • Schedule (Thread Démon) : Gère le cycle de vie (LIFECYCLE). Un thread personnalisé exécute une boucle while True: schedule.run_pending(); time.sleep(60).

Réinitialisation Individuelle (Self-Service)

En complément de la purge globale, l'utilisateur dispose d'une action UI dédiée pour réinitialiser sa propre clé sans intervention administrative.

✅ Audit de Vérité

Le cycle de vie (Lifecycle) est géré par un thread démon dans server.py qui exécute les tâches planifiées toutes les 60 secondes. L'isolation est garantie car ce service communique avec Docker via la socket UNIX locale, sans exposition réseau externe.
