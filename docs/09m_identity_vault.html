9m. ECHO Identity Vault

Gestion sécurisée des secrets, identifiants et clés API pour les orchestrateurs N8N et MCP.

Architecture Sécurisée

L'outil identity_vault_tool.py gère le registre sécurisé des secrets. Il permet au modèle de lister et de manipuler les identités nécessaires à l'exécution de tâches complexes via des services tiers (ex: requêtes HTTP authentifiées dans N8N ou MCP).

Règle d'or de consultation

Le modèle doit impérativement invoquer list_available_services pour découvrir le nom de l'environnement (ex: n8n_workflows) avant d'interroger list_identities, car cette dernière exige un paramètre service précis.

Interface et Synchronisation

L'ECHO Identity Vault bénéficie également d'une interface centralisée (echo_identity_vault_action.py) fusionnant MCP et N8N. Elle se synchronise dynamiquement avec l'API des schémas du MCP Broker et de N8N pour sauvegarder les credentials dans SQLite de manière étanche et chiffrée. Elle orchestre la distribution des secrets via ECHO_N8N_VAULT_KEY.
