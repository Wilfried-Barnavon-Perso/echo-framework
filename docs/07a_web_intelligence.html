7a. Web Intelligence : Navigation & Recherche Souveraine

Pour comprendre le monde extérieur, l'Arsenal met à disposition de l'IA un navigateur et un moteur de recherche souverains.

Fiche d'Identité Technique

🌐 Web Intelligence

Nature : Cluster de Micro-services (Browser Headless + Proxy de recherche).

Source : 12-owui-tools/navigation_engine_tool.py & sovereign_web_search.py. Conteneur : 22-docker-browser-agent/.

Rôle : Fournir à l'IA la capacité de naviguer sur le web public (cliquer, scroller, lire) et de rechercher des informations sans exposer l'utilisateur aux traqueurs (SearxNG).

Exécutant : Ordres émis par le Pipe (Python), exécutés par les conteneurs isolés browser-agent (Node.js/Playwright) et searxng.

Interconnexions :

  • Input : Requêtes structurées de l'IA (URLs, requêtes de recherche, index de clics).
  • Action réseau : Trafic HTTPS sortant vers le World Wide Web via la zone sécurisée.
  • Output : Cartographie DOM (JSON), images Base64 (screenshots), et résultats de recherche parsés au Pipe.

💡 Comprendre la Web Intelligence

ECHO ne se contente pas de "lire" internet. Il possède un Navigateur Fantôme (Chromium) qu'il pilote comme un humain. Il peut cliquer, scroller, et même "voir" la page grâce à des captures d'écran. La Recherche Souveraine signifie qu'il interroge des moteurs de recherche (SearxNG) qui protègent votre anonymat : personne ne sait ce que vous cherchez, pas même Google.

Le module Web Intelligence permet à ECHO d'interagir avec le Web de manière humaine, via une instance Chromium pilotée, un retour visuel en temps réel (HUD), et d'effectuer des recherches sémantiques profondes sans traceur (tracker).

Architecture du Moteur (navigation_engine_tool.py)

Le moteur repose sur une séparation stricte entre le client ECHO et le browser-agent (container Docker isolé). Les communications se font via des requêtes HTTP internes.

Fonctions de Pilotage

Fonction Description Technique
web_browse_navigate Charge une URL, génère une capture d'écran et renvoie la Map du DOM (éléments interactifs indexés).
web_browse_interact Exécute des actions : click, type, scroll, hover, press. Supporte le ciblage par index numérique (recommandé) ou sélecteur CSS.
get_web_object_url Résout les URLs absolues (src/href) à partir des index du DOM détectés. Essentiel pour extraire des images ou des liens profonds.
web_browse_reset Réinitialisation matérielle (Hard Reset) de l'instance Playwright. Supprime cookies et sessions en cas de blocage.

Mémoire Visuelle & Proof Protocol

À chaque interaction réussie, le moteur capture une frame (PNG) et la scelle dans le Vault. La fonction get_browser_frames_history permet au modèle de consulter les IDs des étapes passées pour reconstruire une chronologie visuelle.

Le Replay Visuel (HUD Cockpit)

ECHO permet de "rejouer" intégralement une session de navigation via une interface HUD dédiée. Cette action permet d'analyser les décisions visuelles de l'IA, d'extraire des preuves ou de corriger un parcours.

Accès au Cockpit de Navigation

Le Replay offre des outils avancés : Chronologie atomique, Zoom haute fidélité (v3.6), Crop dynamique et Export sécurisé (Fallback CORS).

Spécifications du DOM Map

ECHO ne lit pas le HTML brut par défaut. Il utilise une fonction de "Highlight" qui transforme le DOM complexe en une liste d'objets simplifiés :

{
  "index": 42,
  "tagName": "BUTTON",
  "text": "Valider le Panier",
  "coordinates": { "x": 120, "y": 450, "w": 80, "h": 30 }
}

Cette abstraction réduit drastiquement la consommation de tokens et améliore la précision du clic.

Recherche Web Souveraine (sovereign_web_search.py)

ECHO n'utilise pas de moteurs de recherche commerciaux traçants. Il s'appuie sur une instance locale de SearxNG et l'API DuckDuckGo.

Outil Moteur Usage Optimal
search_instant_answer DuckDuckGo Faits, définitions, Wikipédia. Réponse ultra-rapide (millisecondes).
search_deep_web SearxNG Actualités, tutoriels, recherches multicritères. Agrège Google, Bing, Brave, etc., sans pistage. Supporte les filtres temporels (day, week, month, year).

Sécurité & Anonymat

Toutes les requêtes web sortantes utilisent le ECHO_USER_AGENT personnalisé. Le proxy SearxNG est sécurisé par un jeton cryptographique généré aléatoirement lors du déploiement (SEARXNG_SECRET), empêchant les moteurs tiers d'identifier l'utilisateur final tout en garantissant l'étanchéité des communications internes.

Visualisation Cartographique Souveraine (gemini_maps_grounding.py)

ECHO v5.140.29 introduit le rendu cartographique interactif basé sur le Rich UI Embedding. Contrairement aux solutions propriétaires, ECHO utilise des technologies open-source pour garantir la confidentialité des recherches géographiques.

Intégration Leaflet & OpenStreetMap

  • Moteur de Rendu : Leaflet.js (v1.9.4) injecté dynamiquement dans l'iframe de discussion.
  • Source de Données : Tuiles OpenStreetMap (OSM) sans clé API et sans pistage publicitaire.
  • Interaction : Cartes entièrement manipulables (Zoom, Pan, Popups) avec marqueurs de position précis.
  • Confidentialité : Les coordonnées sont extraites du groundingMetadata de Google Maps Grounding, mais le rendu final s'effectue dans une enclave HTML isolée.
