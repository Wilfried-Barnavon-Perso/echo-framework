4. L'Écosystème HUD & UI (EchoUI)

Pour interagir avec la complexité des librairies sous-jacentes, ECHO propose des interfaces visuelles claires, regroupées sous l'appellation HUD.

💡 Qu'est-ce que le HUD ?

Le HUD (Heads-Up Display) n'est pas une nouvelle interface graphique, mais une surcouche d'affichage standardisée injectée dynamiquement par-dessus le DOM d'Open WebUI. Il permet d'afficher en temps réel des informations techniques (jauge de contexte, rejeu web, moniteur de performance) directement dans le flux de votre conversation, sans polluer le texte de l'IA.

L'interface utilisateur d'ECHO, baptisée EchoUI, n'est pas une simple surcouche CSS, mais un moteur d'injection dynamique asynchrone. Elle permet de briser le "bac à sable" visuel d'Open WebUI pour offrir une expérience HUD digne d'une station de travail de renseignement.

Architecture de Communication

Le système repose sur une symbiose entre le Backend (Python) et le Frontend (JavaScript) :

  1. Backend (echo_ui.EchoUI) : Génère des payloads JavaScript polymorphes encapsulant les données (Images Base64, métadonnées, états).
  2. Canal d'Événements (EchoEvents) : Utilise les ponts emit et call d'Open WebUI pour injecter le code dans le DOM global.
  3. Runtime Frontend (Engine) : Un objet singleton éphémère (ex: window.echoEngine_HUD_ID) prend le relais pour gérer les interactions locales.

⚙️ Précision Mécanique : Fluidité d'Affichage

L'utilisation des propriétés CSS translate3d et will-change dans les templates JS de echo_utils.py garantit une fluidité d'affichage constante de 60 FPS lors des zooms matriciels (jusqu'à 15x), même sur les captures d'écran haute résolution ou des fichiers PDF complexes.

1. Le Monitor ECHO (Visualiseur Intelligent)

Invoqué via EchoUI.monitor_ECHO, ce composant est le pivot de l'analyse visuelle.

🔎 Détail Technique : Moteur de Rendu & Performance

  • Accélération GPU : Utilisation de translate3d(x,y,0) pour forcer la création de calques de composition matérielle.
  • Calcul de Ratio Dynamique : La fonction getBestSize ajuste automatiquement la fenêtre pour respecter les proportions de l'image (Aspect Ratio).
  • Moteur Zoom & Pan Universel : Navigation haute fidélité via la matrice de transformation CSS (transform: scale()). Ctrl + Molette gère le zoom (jusqu'à 15x), Clic + Glisse gère le Pan.
  • Crop-Box Interactif : Permet de définir une zone d'intérêt via une boîte de sélection redimensionnable.

Persistance de l'État (LocalStorage)

Le HUD implémente une mémoire de session. Chaque manipulation est enregistrée sous la clé STATE_KEY définie par le backend : { "x": 120, "y": 45, "s": 1.5, "ix": 0, "iy": 0, "m": false }.

2. La Context Gauge (Cortex Monitoring)

Injectée dans la barre de navigation via EchoUI.deploy_context_gauge, cette jauge est l'outil de pilotage du "Context Caching" de Gemini.

Compréhension des Segments de Jauge

  • 🟪 Cache (Purple) : Tokens déjà ingérés et mis en cache par Google (économie de coût de 90%).
  • 🟩 User/Prompt (Green) : La charge active du message actuel.
  • 🟧 Generated (Orange) : Les tokens produits par ECHO.
  • ⬜ Vide : Espace de mémoire de travail restant avant saturation.
