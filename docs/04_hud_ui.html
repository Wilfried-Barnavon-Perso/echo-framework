4. Écosystème HUD & UI (EchoUI)

💡 Le Concept en 1 minute

Le HUD (Heads-Up Display) est le Tableau de Bord Immersif d'ECHO. Au lieu de vous donner juste du texte, ECHO injecte des fenêtres interactives directement dans votre chat. Vous pouvez zoomer sur des captures d'écran, surveiller la mémoire de l'IA en temps réel, ou utiliser le Replay pour voir ce que l'IA a fait sur le web. C'est ce qui transforme un simple chat en une véritable station de pilotage.

L'interface utilisateur d'ECHO, baptisée EchoUI, n'est pas une simple surcouche CSS, mais un moteur d'injection dynamique asynchrone. Elle permet de briser le "bac à sable" visuel d'Open WebUI pour offrir une expérience HUD (Heads-Up Display) digne d'une station de travail de renseignement.

Architecture de Communication

Le système repose sur une symbiose entre le Backend (Python) et le Frontend (JavaScript) :

  1. Backend (echo_utils.EchoUI) : Génère des payloads JavaScript polymorphes encapsulant les données (Images Base64, métadonnées, états).
  2. Canal d'Événements (EchoEvents) : Utilise les ponts emit et call d'Open WebUI pour injecter le code dans le DOM global.
  3. Runtime Frontend (Engine) : Un objet singleton éphémère (ex: window.echoEngine_HUD_ID) prend le relais pour gérer les interactions locales.
Sécurité du Flux : Aucune URL de fichier temporaire n'est exposée. Les médias transitent exclusivement via des flux data:mime/type;base64, garantissant l'étanchéité des données entre le Vault et l'affichage.

1. Le Monitor ECHO (Visualiseur Intelligent)

Invoqué via EchoUI.monitor_ECHO, ce composant est le pivot de l'analyse visuelle.

⚙️ Moteur de Rendu & Performance

  • Accélération GPU : Utilisation de translate3d(x,y,0) et will-change pour forcer la création de calques de composition matérielle.
  • Calcul de Ratio Dynamique : La fonction getBestSize ajuste automatiquement la fenêtre pour respecter les proportions de l'image (Aspect Ratio).
  • Moteur Zoom & Pan Universel : Navigation haute fidélité via la matrice de transformation CSS (transform: scale()). Ctrl + Molette gère le zoom (jusqu'à 15x), Clic + Glisse gère le Pan.
  • Crop-Box Interactif : Permet de définir une zone d'intérêt via une boîte de sélection redimensionnable.

Persistance de l'État (LocalStorage)

Le HUD implémente une mémoire de session. Chaque manipulation est enregistrée sous la clé STATE_KEY définie par le backend : { "w": 800, "x": 120, "y": 45, "m": false, "f": false }.

2. La Context Gauge (Cortex Monitoring)

Injectée dans la barre de navigation via EchoUI.deploy_context_gauge, cette jauge est l'outil de pilotage du "Context Caching" de Gemini.

Compréhension des Segments de Jauge

  • 🟪 Cache (Purple) : Tokens déjà ingérés et mis en cache par Google (économie de coût de 90%).
  • 🟩 User/Prompt (Green) : La charge active du message actuel.
  • 🟧 Generated (Orange) : Les tokens produits par ECHO.
  • ⬜ Vide : Espace de mémoire de travail restant avant saturation.

✅ Audit de Vérité (v2.81)

L'utilisation de translate3d et will-change a été confirmée dans les templates JS de echo_utils.py. Ces optimisations garantissent une fluidité de 60 FPS lors des zooms matriciels (jusqu'à 15x), même sur les captures d'écran haute résolution.
