4. L'Écosystème HUD & UI (EchoUI)

Pour interagir avec la complexité des librairies sous-jacentes, ECHO propose des interfaces visuelles claires, regroupées sous l'appellation HUD et pilotées par echo_ui.py.

💡 Qu'est-ce que le HUD ?

Le HUD (Heads-Up Display) n'est pas une nouvelle interface graphique, mais une surcouche d'affichage standardisée injectée dynamiquement par-dessus le DOM d'Open WebUI. Il permet d'afficher en temps réel des informations techniques (jauge de contexte, quota d'API, rejeu web, moniteur de performance) directement dans le flux de conversation, sans polluer le texte de l'IA.

L'interface utilisateur d'ECHO, baptisée EchoUI (14-owui-libs/echo_ui.py v5.19), est un moteur d'injection dynamique asynchrone. Elle permet de briser le bac à sable visuel d'Open WebUI pour offrir une expérience HUD digne d'une station de travail de renseignement.

Architecture de Communication

Le système repose sur une symbiose entre le Backend (Python) et le Frontend (JavaScript) :

  1. Backend (echo_ui.EchoUI) : Génère des payloads JavaScript polymorphes encapsulant les données (images Base64, métriques, états).
  2. Canal d'Événements (EchoEvents) : Utilise les ponts emit et call d'Open WebUI pour injecter le code dans le DOM global.
  3. Runtime Frontend (Engine) : Un objet singleton éphémère (ex: window.echoEngine_HUD_ID) prend le relais pour gérer les interactions locales.

1. Le Monitor ECHO (Visualiseur Intelligent)

Invoqué via EchoUI.monitor_ECHO, ce composant est le pivot de l'analyse visuelle.

⚙️ Précision Mécanique : Fluidité d'Affichage

  • Accélération GPU : Utilisation de translate3d(x,y,0) pour forcer la création de calques de composition matérielle.
  • Calcul de Ratio Dynamique : La fonction getBestSize ajuste automatiquement la fenêtre pour respecter les proportions de l'image (Aspect Ratio).
  • Moteur Zoom & Pan Universel : Navigation haute fidélité via la matrice de transformation CSS (transform: scale()). Ctrl + Molette gère le zoom (jusqu'à 15x), Clic + Glisse gère le Pan.
  • Crop-Box Interactif : Permet de définir une zone d'intérêt via une boîte de sélection redimensionnable.

Persistance de l'État (LocalStorage)

Le HUD implémente une mémoire de session. Chaque manipulation est enregistrée sous la clé STATE_KEY définie par le backend : { "x": 120, "y": 45, "s": 1.5, "ix": 0, "iy": 0, "m": false }.

2. La Context Gauge (Cortex Monitoring)

Injectée dans la barre de navigation via EchoUI.deploy_context_gauge() (v5.19), cette jauge est l'outil central de pilotage de l'état cognitif et des quotas d'API. Elle est mise à jour à chaque tour de conversation par pipe_engine.py.

A. Barre de Contexte (Tokens)

Une barre colorée à trois segments représente l'utilisation de la fenêtre contextuelle :

  • 🟪 Cache (Violet) : Tokens déjà ingérés et mis en cache par Google (économie de coût de 90%). Proportion = cache_pct.
  • 🟩 User/Prompt (Vert) : La charge active du message actuel. Proportion = prompt_pct.
  • 🟧 Génération (Orange) : Les tokens produits par ECHO. Proportion = gen_pct.
  • ⬜ Vide : Espace de mémoire de travail restant avant saturation.

Le tooltip de la barre affiche le détail en tokens absolus : Cache, Prompt actif, Génération, Total / Max.

B. Icône Quota (Jauge Circulaire SVG)

Une icône cadenas à gauche de la barre de contexte représente l'état du quota du modèle CA actuellement utilisé. La jauge circulaire SVG est calculée via stroke-dashoffset à partir de quota_fraction (0.0 → épuisé, 1.0 → plein). La couleur varie selon les seuils :

  • Vert : quota_fraction > 0.50
  • Orange : 0.20 < quota_fraction ≤ 0.50
  • Rouge : quota_fraction ≤ 0.20

C. Tooltip AUTHENTIFICATION / QUOTAS

Au survol de l'icône, un tooltip affiche deux sections :

Section AUTHENTIFICATION
🔐 Source  : méthode d'auth (OAUTH2, API_KEY, etc.)
👤 Compte  : google_user_email (depuis identity.db)
🏗️ Projet  : google_project_id (depuis identity.db)
Section QUOTAS (données fraîches via fetch_available_models)
💳 Crédits      : google_credits_total (crédits AI disponibles sur le compte)
🤖 Modèle CA    : ca_model_id du modèle actuellement utilisé (ex: gemini-3-flash-agent)
📊 Quota        : quota_fraction × 100% — coloré selon seuils (vert/orange/rouge)
📅 Req/jour     : requestsPerDayRemaining / requestsPerDayLimit (N/A si non fourni par API)
⚡ Req/min      : requestsPerMinuteRemaining / requestsPerMinuteLimit (N/A si non fourni par API)
🔄 Reset        : heure de reset du quota — formatée HH:MM (Xmin restantes)
🏷️ Type         : google_quota_type (ex: CODE_ASSIST)

Source des données quota

Le quota est issu de fetchAvailableModels (endpoint CA), stocké dans google_quota_by_model (JSON dict). La méthode EchoAuth.get_model_quota(ca_model_id) extrait le quotaInfo spécifique au modèle utilisé. Les champs requestsPerDay/Min peuvent être absents selon les réponses API — dans ce cas, "N/A" est affiché. Le rafraîchissement est déclenché de manière asynchrone non-bloquante via refresh_quota_if_needed() avec un cooldown de 10 minutes.

D. Signature Complète de deploy_context_gauge()

La fonction principale du HUD accepte les paramètres suivants (tous avec valeurs par défaut) :

Signature deploy_context_gauge — echo_ui.py v5.19
deploy_context_gauge(
    events,                        # EchoEvents — canal d'injection JS
    plan_name, credits_val, quota_str,  # Identité et quotas globaux
    c_t, active_p_t, g_t, max_t,       # Tokens absolus (cache, prompt, gen, max)
    cache_pct, prompt_pct, gen_pct,     # Pourcentages pour la barre (0-100)
    user_email, user_tier, project_id,  # Identité utilisateur
    auth_sources,                       # Liste des méthodes d'auth actives
    quota_amount,      # Montant quota (N/A si non disponible — héritage)
    quota_fraction,    # Fraction restante du quota modèle (0.0-1.0)
    quota_reset,       # Heure de reset (HH:MM ou HH:MM (Xmin))
    quota_type,        # Type de quota (ex: CODE_ASSIST)
    quota_model,       # CA model ID utilisé pour ce quota
    quota_rpd_rem,     # Requests per day remaining (ou "N/A")
    quota_rpd_lim,     # Requests per day limit (ou "N/A")
    quota_rpm_rem,     # Requests per minute remaining (ou "N/A")
    quota_rpm_lim      # Requests per minute limit (ou "N/A")
)
