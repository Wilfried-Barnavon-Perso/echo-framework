7e. Actions UI (HUD)

En termes Open WebUI, une Action est un bouton interactif injecté dans l'interface de chat. ECHO en déploie trois, permettant à l'utilisateur d'effectuer des opérations de maintenance sans ligne de commande. Elles sont définies dans le répertoire 13-owui-actions/.

💡 Actions vs Outils

Les Outils sont déclenchés par le modèle (Tool Call). Les Actions sont déclenchées par l'utilisateur via un bouton visible dans le chat. Elles exécutent un code Python côté serveur mais n'interagissent pas avec le flux de génération Gemini.

Action 1 — Purge Mémoire (memory_purge_action.py)

Supprime tous les souvenirs de la collection echo_memory associés à l'utilisateur courant dans Qdrant. Utile pour repartir d'un historique vierge sans supprimer l'identité d'authentification.

⚠️ Opération irréversible

La purge est définitive. Les souvenirs supprimés ne peuvent pas être restaurés sauf depuis une sauvegarde de volume Qdrant effectuée par l'Admin Manager. L'action présente un dialogue de confirmation avant exécution.

Action 2 — Reset Authentification (auth_reset_action.py)

Invalide tous les tokens OAuth2 et clés API enregistrés dans identity.db pour l'utilisateur courant. Au prochain message, ECHO déclenchera automatiquement un nouveau flux d'authentification PKCE.

Cette action est utile en cas de révocation de droits Google, de changement de compte, ou de suspicion de compromission d'un token.

Action 3 — Cockpit de Replay Web (web_navigation_replay_action.py)

Ouvre une interface HUD permettant de consulter et rejouer les sessions de navigation web effectuées pendant la conversation courante. Chaque action (URL visitée, clic, saisie) est affichée avec sa capture d'écran associée. L'utilisateur peut exporter la session au format JSON ou rejouer une étape spécifique.
