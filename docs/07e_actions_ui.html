7e. Actions UI : Les Commandes du HUD

Les Actions UI sont des modules interactifs injectés directement dans l'interface utilisateur d'Open WebUI. Elles permettent à l'utilisateur de piloter les fonctions critiques du framework via des boutons contextuels, sans passer par des commandes textuelles.

💡 Le Concept en 1 minute

Imaginez que votre IA est un pilote d'avion. Les Outils sont ses commandes automatiques, mais les Actions UI sont les boutons physiques sur le tableau de bord (le HUD) sur lesquels VOUS pouvez appuyer pour reprendre le contrôle manuel sur la mémoire, l'accès ou la vision de l'IA.

1. ECHO Memory Purge (Granulaire) - v2.7

Cet outil de gouvernance permet un élagage chirurgical de la mémoire organique (Qdrant) pour éviter les hallucinations dues à des souvenirs obsolètes ou contradictoires.

🧠 Pourquoi est-ce important ?

Avec le temps, une IA peut accumuler des souvenirs contradictoires (ex: vous avez changé d'avis sur un projet). La purge permet de dire à ECHO : "Oublie tout ce que tu sais sur le Projet X, on recommence sur de nouvelles bases".

⚙️ Sous le capot (Audit Code : v2.7)

  • Tri Hiérarchique : Les catégories sont présentées selon une logique de priorité :
    1. Importance (ASC) : Les souvenirs les plus "faibles" en premier.
    2. Fréquence (DESC) : Les sujets les plus discutés en premier.
  • Code Couleur Sémantique : 🟢 Nv 1 (Trivial) 🔵 Nv 2 (Utile) 🟡 Nv 3 (Structurel) 🟠 Nv 4 (Fondateur) 🔴 Nv 5 (Axiome)

🎯 Guide d'utilisation rapide

  1. Cliquez sur le bouton Purge.
  2. Regardez la liste des thèmes (tags) classés par importance.
  3. Saisissez les numéros souhaités (ex: 1-3 pour tout ce qui est trivial).
  4. Confirmez après avoir lu la prévisualisation (Dry Run). C'est irréversible !

2. ECHO Auth Manager - v3.7

Le gestionnaire d'authentification HUD permet une rotation souveraine des clés API sans intervention de l'administrateur système.

🔑 Pourquoi est-ce important ?

Si votre clé API Google est expirée ou si vous voulez changer de compte, vous n'avez pas besoin de fouiller dans les fichiers de configuration. Vous "nettoyez" votre accès ici, et ECHO vous redemandera proprement vos nouveaux accès au prochain besoin.

⚙️ Sous le capot (Audit Code : v3.7)

L'action cible exclusivement la base identity.db située dans l'enclave utilisateur du Vault. Elle exécute un DELETE FROM auth_data WHERE key LIKE 'google_%'. C'est propre, local et sécurisé.

3. Show Web Replay (Cockpit JS) - v3.6

Véritable "Boîte Noire" de la navigation, le Replay permet d'auditer visuellement chaque étape du navigation_engine_tool.

👁️ Pourquoi est-ce important ?

Parfois l'IA dit : "Je n'ai pas trouvé le bouton Valider". Avec le Replay, vous pouvez voir ce qu'elle a RÉELLEMENT vu à ce moment précis, zoomer sur la page, et comprendre si c'était un bug d'affichage ou une erreur de raisonnement.

⚙️ Sous le capot (Audit Code : v3.6)

  • Moteur Zoom & Pan : Navigation haute fidélité via Ctrl + Molette (Zoom 0.1x à 15x).
  • Streaming Atomique : Python pousse les images une par une vers le navigateur. Le thread Python s'arrête (Promise JS) tant que vous n'avez pas cliqué sur "Suivant" ou "Play".
  • Fallback CORS : Si la sécurité du navigateur bloque la copie, ECHO crée un calque spécial pour vous permettre de faire un clic droit manuel.

🎮 Contrôles du Cockpit

  • Ctrl + Molette : Zoomer/Dézoomer.
  • Clic + Glisser : Se déplacer dans l'image.
  • Bouton ⛶ : Tracer une zone pour l'extraire (Crop).
  • Bouton ❐ : Copier l'image actuelle pour la partager ou l'analyser ailleurs.

✅ Contrôle de Vérité

Toutes les informations ci-dessus ont été vérifiées par analyse statique des fichiers 13-owui-actions/*.py. Aucun "bullshit" : les comportements décrits correspondent aux fonctions SQL, JS et Python réelles du framework.
