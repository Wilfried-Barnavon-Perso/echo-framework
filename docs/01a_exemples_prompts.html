1a. Exemples de Prompts & Autonomie

Comment interagir efficacement avec ECHO et tirer parti de son autonomie complète.

L'Autonomie Pure d'ECHO

ECHO n'est pas un modèle conversationnel standard : c'est un agent autonome. Lorsqu'on lui confie une tâche, ECHO est capable d'analyser le problème, de forger un plan d'action, et d'exécuter ce plan de manière itérative sans intervention humaine. Elle lira des fichiers, cherchera sur le web, compilera du code, et corrigera ses propres erreurs.

L'Adaptation Dynamique via le Kernel

Le comportement d'ECHO s'adapte dynamiquement sans nécessiter de configuration externe. Pour l'utilisateur, le Prompt Système (Le Kernel) est strictement immuable. Cependant, ce cœur cognitif statique contient les méta-principes et les algorithmes qui permettent à ECHO de s'ajuster automatiquement à vos besoins immédiats, qu'il s'agisse de recherche académique ou de développement logiciel brut.

Exemples de Prompts pour Déclencher les Outils

Recherche & Synthèse (Web Intelligence)

"Analyse les 3 dernières publications sur les modèles de langage open-source européens et fais-moi un rapport détaillé."

ECHO déclenchera automatiquement l'outil de navigation Playwright et SearXNG, lira les pages, et synthétisera le contenu.


Développement et Sandbox (Codex & Code Executor)

"Écris un script Python pour nettoyer ce jeu de données CSV, enregistre-le dans le Codex, puis exécute-le dans la sandbox pour me donner les résultats statistiques."

ECHO utilisera le Codex pour créer le fichier, puis l'outil Code Executor pour lancer le script de manière isolée et lire la sortie standard.


Orchestration & Débat (Conseil Delphi)

"Convoque le conseil Delphi avec 3 experts (un architecte cloud, un expert sécurité, un développeur frontend) pour débattre du choix entre AWS et une infrastructure souveraine SecNumCloud."

ECHO instanciera les experts, animera le débat en arrière-plan, et vous fournira le consensus final.
