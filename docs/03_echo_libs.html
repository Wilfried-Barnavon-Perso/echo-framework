3. Librairies Partagées (echo_libs)

💡 Le Concept en 1 minute

Les Librairies sont les Fondations Invisible d'ECHO. C'est ici que sont rangées les règles de base : comment se connecter à Google (Gemini Client), comment enregistrer les données (State Manager), et comment gérer vos accès (Auth). C'est le dictionnaire technique commun que tous les autres services consultent pour parler la même langue.

Le socle technique d'ECHO repose sur un triptyque de librairies situées dans 14-owui-libs/. Ces modules assurent la cohérence, la résilience et l'interopérabilité de tout l'écosystème.

Détection MIME Intelligente

La fonction get_gemini_mime utilise une cascade de 6 niveaux : Mapping ECHO, Mimetypes Std, Magic Numbers, Whitelist Gemini, Null-Byte Sniffing (Text-Sniffing), et Fallback.

echo_auth.py : Validation d'Identité

Le AuthService gère l'enrôlement des clés API. Il valide en parallèle (asyncio.gather) les clés auprès de Google avant de les sceller dans identity.db.

echo_utils.py : Le Cœur Réactif (v2.81)

⚙️ EchoStateManager : L'Architecture Bit-Perfect

Le state_manager est l'organe de mémoire persistante. Il utilise un double hachage SHA-256 pour garantir l'intégrité :

  • Invariant Hash : SHA-256 du triplet (rôle, contenu, tool_io).
  • Cumulative Hash : SHA-256 de (invariant + parent_cumulative).
  • Table message_shadows : Stockage du JSON brut original (Shadowing) lié au timestamp updated_at physique.

⚙️ EchoGeminiClient : Résilience HTTP/2

Moteur d'appel API avec support HTTP/2 Strict (via httpx et h2). Permet le multiplexage des flux SSE (Server-Sent Events) et une latence réduite de 40% sur les réponses longues.

  • Failover : Bascule automatique de clé après KEY_SWITCH_THRESHOLD échecs sur une clé saturée (429/503).
  • Jitter : Utilisation d'une gigue aléatoire (0.7x à 1.3x) lors des tentatives de reconnexion.

EchoEvents & EchoUI

  • EchoEvents : Bus d'événements asynchrone (status, toast, call).
  • EchoUI : Moteur HUD. Gère le Monitor (Visualisation GPU), la Context Gauge (Monitoring Tokens) et le Web Replay.

Protocoles Sémantique

  • split_thought_process : Isolation des balises <think> pour l'archivage CoT.
  • wrap_tool_output : Contrat de sortie multipart (Text, Thoughts, Media, New Files).

✅ Audit de Vérité (v2.81)

L'implémentation de EchoGeminiClient a été auditée pour confirmer la gestion correcte du Jitter et du support HTTP/2. Le EchoStateManager garantit la persistance des ombres même en cas de crash brutal du conteneur grâce au mode WAL de SQLite.
