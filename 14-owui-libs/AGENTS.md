# 🌌 ECHO Framework - Connaissance Sémantique : `14-owui-libs`

> **ATTENTION AGENTS** : Ce document est la base de connaissances sémantique exclusive du dossier `14-owui-libs`. Il complète les règles globales définies dans le `AGENTS.md` à la racine.

## 1. Rôle du Dossier

Ce dossier constitue le **Cœur Applicatif (Core Libraries)** du framework. Il centralise toutes les fonctions utilitaires, la gestion des accès base de données, la sécurité DOM, l'authentification forte, et sert de référentiel absolu (Single Source of Truth) pour les configurations via `echo_constants.py`.

## 2. Cartographie des Fichiers et Algorithmes

### Fondations & Registre Unifié
- **`echo_constants.py`** : C'est le Registre Unifié et la librairie de fondations (Shared Core Functionality, v5.228.9.1). 
  - **Sémantique** : Contient `ECHO_MODELS_REGISTRY` dictant la hiérarchie cognitive dual-backend AI Studio / Code Assist (`MODEL_PROMETHEUS` : `gemini-4-argon` / `gemini-4-argon-high`, `thinkingLevel: "medium"` ; `MODEL_APOLLO` : `gemini-3.8-flash` / `gemini-3.8-flash-high`, `thinkingLevel: "high"` ; `MODEL_ZEPHYR` : `gemini-3.5-flash-lite` / `gemini-3.5-flash-lite`, `thinkingLevel: "high"` ; `MODEL_DISTILLATION` : `gemini-3.5-flash-lite` / `gemini-3.5-flash-lite`, `thinkingLevel: "low"`), les helpers factorisés `get_descending_cascade` (calcul dynamique de la cascade descendante) et `get_generation_config` (forçage factorisé de `thinkingLevel="high"` sur repli 429 via `is_fallback_cascade=True`), la limite unifiée `ECHO_MAX_CONTEXT_SIZE = 1048576` ($2^{20}$ tokens), les constantes audio in-process `ECHO_AUDIO_*` (préfixe `/echo/v1`, voix `fr-FR-VivienneMultilingualNeural`, vitesse nominale `ECHO_AUDIO_DEFAULT_TTS_SPEED = 1.0`, pitch feutré `ECHO_AUDIO_DEFAULT_TTS_PITCH = "-2Hz"`, modèle STT `MODEL_ZEPHYR`, `ECHO_AUDIO_MAX_UPLOAD_SIZE = 14 Mo`), `AEC_REMINDERS` (défibrillateur cognitif 6 axes : `context_hygiene` 140k/65, `kernel` 100k/50, `factuality` 70k/35, `strategy` 60k/30, `alignment` 55k/28, `efficiency` 44k/18), `DELEGATE_AGENT_BLACKLIST` (incluant les outils interactifs Headless-interdits `ask_user_input`, `delete_user_skill`, `manage_identity`, `open_codex_ui`), `ECHO_SESSION_DOMAINS` pour le Vault, `ECHO_CODEX_WORKSPACES` (`main`, `sandbox`), `ECHO_SYNC_EXCLUDE_LIST` (bouclier anti-freeze UI), l'identifiant obligatoire `wrap_tool_output` (`echo_tool_multiparts`) pour le multimodal, le mapping SSOT bidirectionnel `CODEX_LANG_MAP` / `CODEX_LANG_TO_EXT` (incluant `.pdf`, `.svg`, `.csv` et les extensions d'images `.png/.jpg/.jpeg/.gif/.webp/.bmp/.ico`), ainsi que les helpers de classification MIME/binaire factorisés `is_text_mime(mime, ext)` et `is_binary_file(file_path, raw_bytes)`. Contient la définition globale de l'User-Agent furtif (`ECHO_STEALTH_USER_AGENT`), l'identité réseau Antigravity (`_AGY_IDE_VERSION = "2.24.0"`, `cl=1000335682`), les seuils anti-bot (`PRUNE_CONTENT_THRESHOLD = 60000`, `DEFAULT_VISION_GRID_STEP = 48`), la constante de troncature anti-OOM `ECHO_MAX_TOOL_TEXT_OUTPUT_CHARS` (131 Ko) et `ECHO_UCTP_CHUNK_SIZE` (256 Ko).
- **Démembrement de l'ancien `echo_utils.py`** : Le framework a subi une refonte modulaire majeure. Le cœur utilitaire massif a été éclaté en composants ultra-spécialisés :
  - **`echo_state_manager.py`** : Gestionnaire universel de l'état asynchrone SQLite (`EchoStateManager`, v5.226.18.0), incluant le registre KV unifié `echo_settings` (remplaçant les anciennes tables `session_state` et `context_stats` avec injection de connexion dans `save_session_setting` pour prévenir tout deadlock), le suivi RAG O(1) (`is_embedded`), le support `item_type` (`file`/`directory`) pour le Codex Multi-Workspace, et un appel déterministe `ORDER BY updated_at DESC LIMIT 1` avec index `idx_sig_msg_id` pour l'extraction des signatures cognitives. La création de l'arborescence physique est déléguée au filtre Inlet `build_environment_domain.py`.
  - **`echo_gemini_client.py`** : Client natif (v5.226.18.0) implémentant le multiplexage **HTTP/2**, le streaming Zéro-RAM Base64 par blocs de 3 Mo, la Cascade Descendante dynamique (`get_descending_cascade`) avec forçage `thinkingLevel="high"` sur repli 429 (`get_generation_config`), le filtrage strict des `parts` de pensée native (`if not p.get("thought")`) dans `call_distillation`, et le Circuit Breaker OAuth2 (Fast-Failover Intra-Retry silencieux sur codes 401/420/429/503 avec verrouillage dynamique). Il applique une normalisation camelCase stricte (`inlineData`, `functionDeclarations`) pour AI Studio et Code Assist, et isole le RAG des sous-agents via `ECHO_SUBAGENT_CONTEXT`.
  - **`echo_aec.py`** : Module d'orchestration contextuelle (AEC, v5.227.1.1). S'appuie sur un système de templating natif **XML** (`<artifact id="AEC_...">`, dont `render_directive`), intègre `drain_pending_directives` (extraction et purge transactionnelle atomique des `aec_directive` et `aec_event` avant scellement dans le Shadow SQLite), `purge_orphaned_events`, et le tri chronologique FIFO.
  - **`echo_core.py`** : Fonctions cognitives et utilitaires pures (v5.227.1.1 : `build_model_identity`, `convert_owui_tools`, `unbox_tool_output`, `wrap_tool_output`, `filter_tools_by_policy`). Intègre le mécanisme de **FIFO Destructif** dans `wrap_tool_output` pour purger la base SQLite exclusivement des `aec_event` et `aec_directive`, sans altérer les ressources réelles (fichiers, uploads). Ségrege formellement la variable `aec_events` lors de la restitution des outils pour l'isoler dans sa propre balise `<artifact id="AEC_evenement_systeme">`.
  - **`echo_session_clone.py`** : Moteur partagé de duplication atomique et de synchronisation de session (v5.228.4.1), mutualisé entre `echo_chat_cloned_event.py` (`sync_cloned_session`) et `resume_in_new_chat_action.py` (`sync_resumed_session`, `duplicate_session_rag`). Fournit `backup_session_db` (`sqlite3.Connection.backup`), `reassign_session_ids` (réécriture des `chat_id`, marqueurs `_C_{cid}_T_` dans `id`/`name`, chemins `/chats/{cid}/` et réinitialisation à `'ready'` des workflows N8N `deployed_as_*`), `prune_forked_history` (élagage causal sur fork intermédiaire), `purge_conversational_state` (purge de l'historique conversationnel SQLite ainsi que de `last_model_id` et `context_stats` tout en préservant `echo_resources`, `processed_files`, `plans` et `codex_docs`), `duplicate_session_domains` (copie physique `files/`, `codex/`, `n8n_workflows/`, `dependencies/`, recâblage des symlinks, renommage des fichiers `U_{uid}_C_{cid}_T_*` et réécriture du frontmatter `chat_id` des plans dans `codex/main`), `align_codex_git_to_cutoff`, pré-marquage `is_embedded = 1` des messages initiaux de synthèse dans `sync_resumed_session`, et `duplicate_session_rag` (clonage paginé des vecteurs Qdrant `COLLECTION_SESSION_RAG` avec `with_vectors: True`).
  - **`echo_http.py` (v5.226.18.0)**, **`echo_events.py` (v5.228.2.1)**, **`echo_logger.py` (v5.226.18.0)**, **`echo_paths.py` (v5.226.18.1)**, **`echo_prompts.py` (v5.227.1.1)** : Briques fondamentales gérant respectivement les requêtes HTTP, évènements OWUI, log, chemins absolus (et verrous asyncio de clonage `_CHAT_CLONE_LOCKS`, `get_chat_clone_lock`, `wait_for_chat_clone`), et gabarits de prompts. **`echo_http.py`** s'appuie désormais sur l'User-Agent furtif global. **`echo_events.py`** (façade UI, v5.228.2.1) émet les toasts via l'événement natif `"notification"` d'Open WebUI, durcit `confirm()` (`return res is True` après exclusion des dictionnaires d'erreur) et intègre nativement le protocole **UCTP (Universal Chunked Transfer Protocol)** (`emit_execute` & `call_execute`) qui fragmente les volumineux scripts JS en blocs de 256 Ko couplés à un HUD visuel de transfert. Il délaisse totalement les heuristiques JS pour l'injection explicite et stricte du contexte métier (`chat_id`, `message_id`, `model_id`, `session_id`) dans `trigger_action` (en vérifiant en outre `data-chat-id === chat_id` et `typeof window.echoCodexResolve === 'function'` sur `#echo-codex-hud` dans le fast-path), ce qui élimine définitivement les crashs en boucle du serveur et les collisions inter-sessions lors d'un fork. Le fichier `echo_prompts.py` inclut quant à lui `ECHO_FOUNDATION_KERNEL`, les domaines `SYS_RAG_DISTILL`, `SYS_ORCHESTRATOR_N8N_GRAPHER`, `USR_AUDIO_TRANSCRIBE`, ainsi que `USR_ACTION_RESUME_GLOBAL` et `USR_ACTION_RESUME_RECENT` pour la distillation en 2 passes lors de la migration de session.
- **`echo_protocol.py` (v5.226.18.0)** : Adaptateur de protocole sans état traduisant les paramètres abstraits ECHO vers le format API Gemini (AI Studio et Code Assist v1internal : `get_ca_model_id`, `build_ca_generation_config`, `CA_EXCLUDED_GEN_CONF_FIELDS`).

### Interfaces Utilisateur (UI & DOM)
- **`echo_ui.py` (v5.228.6.2)** : Moteur de rendu UI de base.
  - **Sémantique** : Responsable de la génération dynamique de code HTML/CSS/JS (Data Islands). Il implémente un système sophistiqué **"OWUI Tools"** avec de fortes optimisations natives mobiles (`get_mobile_guard_js` : dvh, touch targets de 44px min, anti-scroll du document, anti-zoom iOS). Il injecte des modales natives asynchrones refactorisées sans effet spaghetti (`get_custom_modals_js` : `window.echoCustomConfirm`, `window.echoCustomPrompt` pour les saisies LLM, doté de boutons 'pills' interactifs, `window.mcpAlert`) qui respectent le mode sombre/clair sans bloquer l'Event Loop de WebUI, tout en sécurisant les rendus via la fonction d'assainissement **`window.echoSanitizeHTML`** (`get_sanitize_html_js`). Affiche dans `deploy_context_gauge` le `Tier` utilisateur, la déduplication du `Project ID` Tenant, ainsi que les jauges **Quota 5h** et **Quota Semaine**. Gère également le support d'impression (`get_print_isolation_js` : `allow-modals`) pour les actions PDF, et intègre la **synchronisation asynchrone de l'URL** en temps réel (`echoWebPlayerUpdate`) pour le HUD Live du navigateur autonome. Le module d'Identity Vault est factorisé sous la classe unifiée `EchoFloatingWindow`, tandis que le Cognitive Monitor (`#echo-cognitive-monitor`, estampillant `data-chat-id` avec auto-close sur changement de route SPA `/c/{id}`) conserve une architecture spécifique pour éviter les lenteurs DOM. Il abandonne le vieux Pattern Data Island au profit du Multiplexage natif UCTP (`emit_execute`) pour l'ECHO Sandbox Monitor (`get_floating_monitor_js`). Il embarque le dictionnaire global d'icônes SVG `ECHO_ICONS` permettant de remplacer la logique applicative lourde par des composants légers, purgeant les composants Vibe Coding massifs ou inutiles.
- **`echo_codex_ui.py` (v5.228.8.1)** : Moteur de rendu UI dédié au HUD ECHO Codex (`EchoCodexUI(EchoUI)`).
  - **Sémantique** : Hérite intégralement d'`EchoUI` et factorise les primitives partagées (`cls.get_mobile_guard_js()`, `cls.get_custom_modals_js()`, `cls.get_print_isolation_js()`). Responsable de la génération du cockpit Monaco et de l'Éditeur Hexadécimal virtualisé (`_generate_codex_js` : `#echo-codex-hud-monaco` / `#echo-codex-hud-hex`) et du support du trigger asynchrone JS `_echoCodexTarget` pour le ciblage de fichiers. Le HUD `#echo-codex-hud` estampille `data-chat-id` et se ferme automatiquement en cas de changement de route SPA (`/c/{id}`). Il intègre une file d'attente RPC résiliente avec watchdog et auto-reconnexion post-standby (`reconnect_only: true` + réveil sur `visibilitychange`), une détection de langage et de binarité factorisée depuis `echo_constants` (`CODEX_LANG_MAP`, `CODEX_LANG_TO_EXT`, `detectIsBinary`), un éditeur hexadécimal interactif (`Offset (8 hex)` | `16 octets Hex` | `16 caractères ASCII`, barre d'inspection binaire `UInt8/Int8/UInt16LE/Bin`, boutons `+ Octet`/`- Octet`, accesseur unifié `getActiveContent()` pour la sauvegarde `Ctrl+S`/💾 via transport bijectif `latin-1`), un registre déclaratif extensible `PREVIEW_REGISTRY` (`markdown`, `html`, `css`, `xml`/SVG, `pdf`, `image`) avec auto-ouverture de la prévisualisation au chargement d'un fichier éligible tout en restant désactivable/activable manuellement via le bouton `👁️` (`#echo-codex-hud-preview-toggle`), des icônes Importer/Exporter normalisées (flèche entrante sur Importer, flèche sortante sur Exporter), un input d'import DOM universel (`arrayBuffer`), et un sélecteur de modèle aligné sur `Apollo`, `Prometheus` et `Zephyr`.
- **`echo_visuals.py` (v5.226.18.0)** : Traduction des concepts générés par le LLM (arbres, graphes) en composants web interactifs (via d3.js, Leaflet ou vis-network).

### Authentification Google OAuth2 / PKCE & Quotas Cloud
- **`echo_auth.py` (v5.228.3.2)** : Gestionnaire d'authentification Cloud (`EchoAuth` & `AuthService`).
  - **Sémantique** : Gère les identités Google OAuth2 (PKCE) et clés API persistées dans `identity.db` (table `auth_data`). Rafraîchit proactivement le token OAuth2 dans `refresh_quota_if_needed()` avant l'interrogation des endpoints Cloud, récupère les quotas glissants **5 heures** et **Hebdomadaire** via `:retrieveUserQuotaSummary` (`google_quota_summary` : `quota_5h_fraction`, `quota_5h_reset`, `quota_5h_disabled`, `quota_weekly_fraction`, `quota_weekly_reset`), traite l'omission Protobuf v3 de `remainingFraction` comme `0.0` (quota épuisé) dans `fetchAvailableModels` avec ciblage prioritaire des modèles Gemini sur le fallback legacy, verrouille l'endpoint du Circuit Breaker sur `httpx.RequestError` (avec journalisation typée et Auto-Heal `unlock_agy_endpoint` sur `200 OK`), et persiste les crédits AI (`google_g1_credits`).
  - **Fallback API Keys** : Implémente la méthode `validate_and_save_api_key` traitant les clés API Google (AI Studio) comme solution de secours si le flux OAuth2 échoue. Valide le réseau (`/models?key=...`) et sauvegarde en `AUTH_METHOD_KEY_PRIMARY` et `SECONDARY` dans SQLite.
- **`echo_pkce_server.py` (v5.226.18.0)** & **`echo_ssh_tunnel.py` (v5.226.18.0)** : Implémentent le flow OAuth2 PKCE strict via un serveur callback éphémère et un tunnel SSH (Ports 8020-8024).

### Pipelines Spécialisés
- **`echo_ingestion.py` (v5.228.7.1)** : Pipeline d'Ingestion Zéro-RAM asynchrone modulaire pour la base RAG. Gère de façon dynamique les fichiers entrants ("dynamic file handling") en s'appuyant sur `is_text_mime` (`echo_constants.py`), les convertit via MarkItDown et les indexe via traitement hybride.
- **`echo_codex_git.py` (v5.228.8.2)** : Surcouche bas niveau (`dulwich`) des opérations Git du Codex multi-workspaces (`main` / `sandbox`). Intègre la lecture/écriture binaire sans perte via transport bijectif `latin-1` (`is_binary_file` importé de `echo_constants.py` dans `commit_file`, `read_file`, `list_directory`, `get_file_at_commit`), une méthode d'accès O(1) (`get_latest_state`), `restore_repo_to_timestamp(cutoff_ts)` pour réaligner l'arbre de travail et `HEAD` lors d'un fork intermédiaire, protège `read_file` via `os.path.isfile` contre `IsADirectoryError`, découvre les dossiers physiques vides créés via l'UI dans `list_directory` (workspace `main`), applique strictement `ECHO_SYNC_EXCLUDE_LIST` lors du parcours `os.walk` pour prévenir le gel UI sur la sandbox, et retourne le tuple `(commit_hash, paths_to_rm)` dans `delete_file` pour garantir la purge SQLite récursive côté action.
- **`echo_browser_lib.py` (v5.226.18.0)** : Bibliothèque bas niveau de pilotage asynchrone pour le worker Playwright (utilisé par `navigation_engine_tool`). Intègre les actions de ciblage géométrique de précision multimodale (`action_zoom_in` et `action_zoom_out`) utilisant le Viseur Rouge.
- **`echo_skills.py` (v5.226.18.0)** : Extracteur sémantique de métadonnées pour les Skills Antigravity.
- **`echo_audio.py` (v5.226.18.0)** : Pont audio in-process hébergeant les endpoints compatibles OpenAI `/echo/v1/audio/transcriptions` (STT Gemini `MODEL_ZEPHYR`, `maxOutputTokens=8192`, `thinkingLevel=minimal`, limite 14 Mo, avec sniffing des magic bytes audio WebM, WAV, OGG, FLAC, MP3, MP4/M4A via `sniff_audio_mime_type`), `/echo/v1/audio/speech` (TTS streaming `audio/mpeg` via `edge-tts`, voix par défaut `fr-FR-VivienneMultilingualNeural`, vitesse nominale `1.0` / `+0%`, et pitch feutré `-2Hz`), ainsi que `/echo/v1/audio/models` et `/echo/v1/audio/voices`. La fonction `register_echo_audio_routes()` s'injecte de manière idempotente en position 0 du routeur FastAPI pour surclasser `SPAStaticFiles`.
- **`echo_constants.py`** : Expose la variable native `ECHO_SUBAGENT_CONTEXT` (`contextvars.ContextVar`) permettant la "télépathie" d'identité inter-fonctions pour propager le flag `is_subagent` à travers les limites du réseau asyncio (contournement du proxy OWUI).
